# Практические занятия №1 и №2 — ПО объектов наземной инфраструктуры

Среда разработки: **Qt Creator**, Qt 6.12, MinGW 64-bit, CMake, C++17.

| Проект | Задание |
|---|---|
| `Practical_01_Classes` | Практика 1, задание 1, вариант 1 — класс `Drone`, управление полётом и аварийная посадка (консоль) |
| `Practical_02_QTTelemetry` | Практика 2, задание 1, варианты 1 и 2 — класс `Vector3D` и перегрузка операций (консоль) |
| `Practical_01_3D` | Практика 1, графическая версия: форма Qt Designer + 3D-сцена Qt Quick 3D (пульт управления дроном) |
| `Practical_02_3D` | Практика 2, графическая версия: 3D-визуализация векторов скорости и перемещения |

`Защита_Практика1_Практика2_с_3D.docx` — пояснения к заданиям, разбор кода, ответы на контрольные вопросы и подготовка к защите.

## Запуск

1. Qt Creator → File → Open File or Project → `CMakeLists.txt` нужного проекта.
2. Комплект **Desktop Qt 6.12.0 MinGW 64-bit** → Configure Project.
3. Ctrl+R.

Проекты нужно хранить в папке без русских букв в пути (например, `C:\QtProjects`), иначе сборщик MinGW не найдёт файлы.
Для графических версий нужны модули Qt Quick, Qt Quick Widgets и Qt Quick 3D.
